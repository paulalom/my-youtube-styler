# My YouTube Styler v0.7.2

Signed Firefox build for regular Firefox installs.

## Install

1. Download `d286352590454dc89781-0.7.2.xpi` from this release's assets.
2. Open the `.xpi` in Firefox, or drag it into a Firefox window.
3. Accept the Firefox install prompt.
4. Open or reload `https://www.youtube.com/` or `https://www.youtube.com/feed/subscriptions`.

This is an unlisted/self-distributed Firefox add-on. It is signed by Mozilla for installation in regular Firefox, but it is not publicly listed on AMO.

## Update

For future versions, install the newest signed `.xpi` from the latest release. Firefox treats it as the same add-on because the manifest keeps the same Gecko ID: `my-youtube-styler@local`.

## Notes

- No launcher is required.
- No remote-control/debugging indicator is expected.
- The extension stores settings locally and does not make network requests.
- Seen-video history remains local and is disabled in private browsing windows.
